# Orange Capitals V83 — Combined Frontend + Backend Package

This ZIP contains the integrated Hostinger deployment project at its root:
- React/Vite frontend (`src/`, `public/`, `index.html`)
- Node.js/Express backend (`server.js`, `backend/`)
- MySQL schema (`backend/sql/schema.sql`)
- Hostinger deployment instructions (`HOSTINGER_DEPLOYMENT.md`)

The `reference/` folder contains the untouched approved V83 frontend ZIP as a backup/reference. Deploy the integrated project at the ZIP root; do not deploy the reference ZIP.

Before deployment, follow `HOSTINGER_DEPLOYMENT.md`. Configure real database credentials and secrets only in Hostinger environment variables. Do not put live credentials in frontend files or share them in chat. Test authentication, branch permissions, persistence, backups, and financial calculations before entering real customer data.
